# Изменения

## 0.1.6 (13.11.2026)

Устойчивость к искажённым комплектам. Дефекты 0.1.5 нашло испытание scii-adversarial: на 724 искажённых комплектах гейт ни разу не допустил неподлинный образ, но 304 раза завершился исключением без решения, 8 раз исчерпал память и 4 раза завис.

- Пути комплекта раскрываются через `realpath` и должны оставаться внутри комплекта. Символическая ссылка за его пределы, абсолютный путь, путь с `..` наружу и поле не строкового типа дают F этого свидетельства.
- Файлы комплекта читаются функцией `read_limited`: только обычные файлы и не больше `MAX_FILE` (64 МиБ). Устройства, каналы и каталоги не читаются. Распакованный образ apj ограничен `MAX_IMAGE` (32 МиБ), что закрывает zlib-бомбу.
- Любая ошибка разбора предъявленного свидетельства даёт F с причиной, а не аварию. Свидетельство, которое предъявлено, но не проверяется, считается опровергнутым, как и раньше.
- Неразбираемый `bundle.json`, свидетельство не в виде объекта и пакет вне комплекта или не обычный файл дают отказ (код 30): все свидетельства F, причина в отчёте. Ошибка чтения политики даёт код 2.
- Тесты `tests/test_bundle_robustness.py` (11): путь вне комплекта, поле неверного типа, неразбираемый комплект, ссылки на `/dev/zero` вместо объектов git и пакета, ссылка внутри комплекта, zlib-бомба, предел чтения.
- Решения на 16 опубликованных комплектах стенда не изменились (`tests/test_data_bundles.py`).

## 0.1.5 (06.11.2026)

- Пакет `paper/evidence-graph-method` приведён к редакции статьи от 06.11.2026. Из статьи убрана таблица близких методов, поэтому таблица решений политик на 16 сценариях стенда стала табл. 4. Подписи вывода, README и ключи JSON (`table4`, `table4_decisions`, `table4_thresholds`, `table4_same_box`, `table4_details`) переименованы. Числа не изменились, сверка 85 из 85.
- Правило (4) сравнивает границы индекса с порогом с абсолютным допуском `THETA_TOL = 1e-9`: допуск при R_P^min >= θ - 1e-9, отказ при R_P^max < θ - 1e-9. Раньше сравнение было строгим, и значение, равное порогу в точной арифметике, могло проиграть ошибке округления. Пример: R_P^min эталона стенда равен 0,4968 точно, но вычисляется как 0,4967999999999999, поэтому при θ = 0,4968 гейт выдавал ручное рассмотрение вместо допуска. При пороге стенда 0,496 и всех порогах статьи решения не изменились.
- Тест `tests/test_threshold_equality.py`: решения модуля совпадают с расчётом в рациональной арифметике на всех 16 сценариях стенда при порогах, равных точкам смены решения, и рядом с ними, для N(w) и B(w); включённая граница допуска, строгая граница отказа, полуинтервал порога статьи 0,46512 < θ <= 0,4968.
- Пакет `paper/evidence-graph-method`: тот же допуск в правиле (4), проверка решений на обеих границах полуинтервала, сверка 85 из 85. Аннотация статьи без числовых сравнений, версия в сноске 0.1.5.

## 0.1.3 (02.11.2026, без отдельного выпуска, вошла в 0.1.4)

- Рекурсия (2) работает за O(|V| + |E|): входящие рёбра каждой вершины хранятся списком, топологический порядок строится алгоритмом Кана с очередью. Прежняя реализация перебирала все рёбра для каждой вершины, O(|V||E|). Значения индекса и решения не изменились: по всем 16 сценариям прогона они побитово совпадают с `results/results.json`.
- Правило (4) с ящиком классов B(w): ключ `--uncertainty box` в `scii-gate evaluate` и `verify`, функции `interval_box` и `bounds` в `scii/model.py`. Ящик допускает сдвиг класса на соседний у любого числа рёбер сразу. Индекс не возрастает по весу каждого ребра, поэтому крайние значения считаются двумя проходами в угловых наборах классов. По умолчанию по-прежнему используется окрестность N(w).
- Замер масштабирования `bench/scaling.py`, результаты в `results/scaling/`.
- Тест `tests/test_complexity_box.py`: вес каждого ребра читается за проход один раз, графы из 20 тыс. вершин считаются за секунды, крайние значения на ящике совпадают с полным перебором, на стенде правило с ящиком при пороге по той же процедуре даёт те же решения.
- Пакет `paper/evidence-graph-method` обновлён по второй редакции статьи. Калиброванные пороги в табл. 3, вариант бинарного контроля с обязательной пересборкой, табл. 5 с решениями пяти политик на всех 16 сценариях стенда и разметкой «опасный» или «штатный» из программы испытаний, диапазон порога, при котором решения не меняются, перебор весов α на стенде. Записи 5 и 6 прежней редакции удалены.
- Версия пакета в `pyproject.toml` и `scii/__init__.py` приведена к номеру выпуска (было 0.1.0).
