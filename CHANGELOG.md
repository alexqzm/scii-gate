# Изменения

## 0.1.2 (31.10.2026)

- Добавлен пакет `paper/evidence-graph-method`: пересчёт всех чисел статьи о методе (редакция для журнала «Вопросы кибербезопасности»), в том числе таблицы записей реальной цепочки ArduPilot по состояниям прогона 30.10.2026. Пакет работает на чистом Python без зависимостей.
- Тест `tests/test_paper_evidence_graph_method.py`: пакет воспроизводит числа статьи, его записи реальной цепочки совпадают с `results/results.json`, а значения табл. 5 совпадают с расчётом `scii/model.py`.
- Код гейта, профили, политика и результаты испытаний не менялись.

Комплекты из архива 0.1.0 (DOI 10.5281/zenodo.23833593) не воспроизводят решения прогона. Правило ограничено корнем репозитория, свидетельства добавлены.

- Ссылка на DOI Zenodo в README и CITATION.cff.
