# Логотип SCII

| Файл | Назначение |
|---|---|
| `scii-logo.svg` | основной вариант для светлого фона |
| `scii-logo-dark.svg` | для тёмного фона |
| `scii-logo-mono.svg` | одноцветный. Цвет задаёт `currentColor`: в документе он чёрный, на веб-странице берётся цвет текста |
| `scii-mark.svg`, `scii-mark-dark.svg` | только знак в квадрате, для аватаров, значков и титульных слайдов |
| `scii-logo.pdf` | вектор для LaTeX и типографии |
| `scii-logo.png`, `scii-logo-dark.png` | растр шириной 2000 пикселей, прозрачный фон |
| `scii-mark-512.png` | знак 512 × 512 |
| `social-preview.png` | превью репозитория 1280 × 640 (GitHub, Settings → Social preview) |
| `scii-logo-source.png` | исходный растровый образец |

Векторные файлы построены по исходному образцу из геометрических примитивов: окружностей, отрезков, скруглённых углов. Радиусы и кромки подобраны по совпадению с образцом. Доля совпадающей площади фигур с образцом при наложении 0,989.

## Цвета

| Элемент | Светлый фон | Тёмный фон |
|---|---|---|
| Узлы, тонкие линии, надпись | `#012450` | `#E6EDF3` |
| Левая диагональ знака (градиент) | `#00325B` → `#003F68` | `#CBE4EA` → `#B6DEE3` |
| Правая диагональ и торец | `#01A4A4` | `#01A4A4` |

Вокруг логотипа стоит оставлять свободное поле не меньше диаметра узла знака.
